# Tasks App

#### Video Demo:(https://youtu.be/xQppHGdTHK0)

## Description

Tasks App is a simple web application that helps users manage their daily tasks efficiently. The application allows users to create, edit, and delete tasks through an easy-to-use interface.

This project was developed using HTML, CSS, and JavaScript. The main goal was to create a lightweight task management system that demonstrates front-end web development concepts such as DOM manipulation, event handling, and local data management.

## Features

- Add new tasks.
- Display the current date when a task is created.
- Edit existing tasks.
- Delete tasks.
- User-friendly interface.
- Responsive design for different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
